# Visuals — The Man Who Survived Two Atomic Bombs

53 shot images, 1920×1080, one per shot in `scripts/shot-list.md`. File names carry the shot number and its start time in the voiceover (`shot18_0m48.7s.jpg` starts at 0:48.7), so placing each image at its start time and holding it until the next one syncs the whole video.

- `shots/` — the 53 images, text-free.
- `text-overlays.md` — the 20 on-screen words to add in CapCut, with exact times.
- `contact-sheets/` — overview grids with shot number and time range.
- `character-sheet/sheet-A-clean.png` — the approved cast sheet (`sheet-B-doodle.png` was the alternative).
- `character-sheet/refs/` — one crop per character, used as the reference for every shot.
- `shot_prompts.json` — the exact prompt, character references and Higgsfield job id behind each image, for retakes.

Generated with Higgsfield Nano Banana Pro at 2K, 16:9, then centre-cropped to 1920×1080.
